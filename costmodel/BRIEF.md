# 推理算力成本：一页结论

**说明**：完整版见 `REPORT.md` / `推理算力成本评估报告.docx`。本文只留能直接用的判断，数字都来自本仓库实测。

## 一句话

在"不缓存答案、每次都自主生成"的约束下，能省的只有**少算**和**少搬**。
实测下来最大的杠杆不是量化、也不是稀疏，而是 **batch**（26.7×），真正的天花板是 **KV 容量**而不是算力。

## 六条可以直接抄走的判断

1. **先上 batch，再谈别的。** 1→32 吞吐 26.7×（dense 4B）/ 18.3×（30B-A3B），不改权重、不改输出、不用重训。成本几乎为零。
2. **量化是乘法，但别期待无损。** W4A16：字节 ×1.65、时间 ×1.45；PPL 15.17 → 17.08（+12.6%），可任务准确率只差 1/32。损伤在"信心"，不在"答错"。
3. **KV 容量才是天花板。** 24 GB 卡上 50,160 token。batch×ctx 一超就排队，吞吐反而掉（batch 8→16 时 610 → 526 t/s）。
4. **Ada 上不要开 fp8 KV。** 一开就退出 FlashAttention 换 XFormers，净亏 21–26%。同样的事在 llama.cpp 里用 q8 KV 只慢 8.9%——问题在引擎，不在硬件。
5. **MoE 专家不要卸载。** 卸载第一层就掉 83%（268.9 → 46.7 t/s），是断崖不是斜坡。装不下就换更小的 MoE，或者干脆 batch 1。
6. **投机解码的收益由文本决定。** 复述型 1.5–1.9×，自由生成只有 1.05×。宣传里的 2.8× 是乐观上限。

## 数字速查

| 场景 | 关键数字 |
|---|---|
| 笔记本 8GB，1.7B Q4 | 188.8 tok/s，5.30 ms/token，带宽兑现 320 GB/s（71%） |
| 笔记本 8GB，OLMoE 1B 激活 | 244.0 tok/s，同体积比 dense 7B 快 3.6× |
| 4090 24GB，4B bf16 | batch 1：98.6 t/s；batch 32：2,635.8 t/s（单步只涨 20%） |
| 4090，30B-A3B GPTQ | batch 1：135.2；batch 32：2,474.1（18.3×） |
| 长上下文（4090） | 每 1,000 token 加 0.19 ms；边际带宽 776 GB/s |
| prefill（笔记本） | dense 34–36 TFLOPS（57–60% 标称），MoE 22.5（37%） |
| 功耗（4090，4B） | 3,077 → 125 mJ/token（24.6×），功率只涨 6% |
| 量化精度（4B W4A16） | PPL +12.6%，多选题 28/32 → 27/32 |

## 判据：方案优化还是程序优化

问一句：**要不要换权重、改计算图。**

- 换 = 方案优化（量化、KV 量化、稀疏注意力、投机解码、MoE）→ 收益是乘法，能叠加
- 不换 = 程序优化（kernel、融合、调度、PD 分离、batching）→ 收益天花板被带宽钉死
- 程序优化的上限可以算：实测带宽 320 GB/s（笔记本）/ 801 GB/s（4090），读多少字节就要多少时间

## 选型：按场景直接抄

| 场景 | 选什么 | 别做什么 | 能拿到多少 |
|---|---|---|---|
| 单卡·高并发·短文本 | vLLM + 尽量大的 batch | 别开 fp8 KV | 26.7×（dense）/ 18.3×（MoE） |
| 单卡·长文本 | Ada 上 vLLM 用 bf16 KV；小卡可上 llama.cpp q8 | vLLM + fp8 KV（−21~26%） | 每千 token 只加 0.19 ms |
| 显存 <16 GB | 换更小的 MoE，或 dense 上 INT4 | **绝不 CPU 卸载专家**（第一层 −83%） | 30B-A3B Q4 只剩 8.4 t/s |
| 半重复输出（补全、改写） | 投机解码 ngram / EAGLE | 自由创作场景别开（1.05×） | 复述 1.5–1.9× |
| 长 prompt 批处理 | chunked prefill；多卡才谈 PD 分离 | 别指望投机解码救 prefill | prefill 打满 57–60% 算力 |
| 精度敏感 | W4A16 可用，准入必须带 PPL | 只看任务准确率 | PPL +12.6%，题只多错 1/32 |

## 什么时候这些结论不成立

- **多卡**：EP/TP 的 all-to-all 一次没测，MoE 在多卡上可能重新划算
- **PD 分离**：prefill 和 decode 抢同一张卡的成本没建模
- **精度**：只测了 4B 的 W4A16 一个点、32 道题、一份英文语料
- **笔记本数字**：热机会低 10–15%，同场比值可靠，绝对值只代表"这一台这一天"
